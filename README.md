# Interactive Portfolio

A static, responsive portfolio using HTML, CSS and JavaScript. No packages, database or subscription required.

## Customize
Open `script.js` and update the `profile` object at the top, including your name, research, projects, publications, social URLs and email. Sample projects and publications are placeholders, not factual claims.

## Run locally
Open `index.html` in a browser. Alternatively, from this folder run `python3 -m http.server 8000` and visit http://localhost:8000.

## Deploy for free on GitHub Pages
1. Create a **public** repository on GitHub (for example `my-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the **repository root**, or use Git to push them.
3. In the repository, choose **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**. Choose `main`, folder `/ (root)`, then **Save**.
5. Once published, your site will be available at `https://YOUR-USERNAME.github.io/my-portfolio/`.

For a root website URL, instead name the repository `YOUR-USERNAME.github.io`.

GitHub Pages serves static frontend code; the included site needs no backend. Review the current GitHub Pages plan and repository visibility requirements if you prefer a private repository.
